# Marilyn

Marilyn is a locally running experimental conversational AI built to explore **memory-heavy data models**, **probabilistic character-level text generation**, and **personality shaping through training data** rather than large pretrained neural networks.

This project focuses on **systems-level experimentation and tradeoff analysis**, not polished language output. Expect imperfect grammar, short conversational context, and highly mechanical responses. This is intentional.

---

## What Marilyn Is (and Isn’t)

**Marilyn is:**

* A fully local conversational AI
* A research project exploring alternative AI architectures
* Focused on memory, probability, and training-data personality shaping
* Designed for experimentation and learning

**Marilyn is NOT:**

* A large language model
* Cloud-connected
* Fluent or production-ready
* Designed for real-world deployment

---

## System Requirements (Minimum)

Because Marilyn loads large memory structures directly into RAM, it has relatively high system requirements.

**Required:**

* 16 GB system RAM minimum
* Modern 6-core CPU (Ryzen 5 / Intel i5 class or better)
* SSD required (NVMe strongly recommended)
* Windows x64

### Step 2 — Run

1. Open the downloaded folder
2. Launch the **Marilyn executable shortcut** located in the root directory
   (this shortcut points to the correct build output internally)
3. When prompted, enter:

'1' to start **Chat Mode**.

The train option is still available, however understand that additional training under heave text files can easily balloon past a typical machine's resources.

---

## What to Expect

Marilyn currently has:

* Very short conversational memory
* Broken or awkward English output
* Highly literal responses
* Limited contextual awareness

These limitations are intentional and reflect the experimental nature of the architecture.

---

## Project Goals

This project exists to explore:

* Memory-heavy AI architectures
* Character-level probabilistic generation
* Training-data-driven personality modeling
* Performance tradeoffs in non-neural conversational systems

It prioritizes **understanding system behavior** over achieving high-quality conversational output.

## Current Status

Marilyn is an **experimental prototype** and closed for development, for now.. Expect instability, rough edges, and incomplete features.
