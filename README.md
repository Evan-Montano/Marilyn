Description:
Marilyn is a locally running experimental conversational AI built to explore memory heavy data models, probabilistic character level generation, and personality shaping through training data rather than large pretrained models. The project prioritizes system level experimentation and tradeoff analysis over fluent or production ready language output.

How to run: 
- Click on the "Marilyn" executable shortcut.
- Enter '1' for Chat mode.
- Enjoy some broken English and a short attention span :)

System Requirements (minimum): 
RAM: 16 GB total system RAM 
CPU: Modern 6-core CPU (Ryzen 5 / i5 class) 
Storage: SSD mandatory, NVMe strongly preferred 
OS: x64Windows
